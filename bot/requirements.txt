# Strategy code needs an IANA timezone database: window localisation, the
# DST guards, and the system-clock -> New York conversion all use `zoneinfo`.
# Linux/macOS read it from the OS; **Windows ships none**, so `zoneinfo` raises
# there unless this free package is installed. `mt5_live_source.ensure_environment()`
# checks for it at startup and fails with an actionable message rather than a
# traceback.
tzdata>=2024.1  # IANA timezone database (free, PyPI)
